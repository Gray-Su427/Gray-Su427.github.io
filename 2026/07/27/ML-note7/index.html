《机器学习》自学日记（七）

第七章 贝叶斯分类器

7.1 贝叶斯决策论

核心思想：在概率框架下，基于后验概率和误判损失选择最优类别标记。

条件风险（期望损失）： \[ R(c_i \mid x) = \sum_{j=1}^{N} \lambda_{ij} P(c_j \mid x) \]

贝叶斯判定准则：为最小化总体风险，每个样本选择使条件风险最小的类别： \[ h^*(x) = \arg\min_{c \in \mathcal{Y}} R(c \mid x) \]

\(h^*\) 称为贝叶斯最优分类器，\(R(h^*)\) 称为贝叶斯风险，\(1 - R(h^*)\) 是模型精度的理论上限。

0/1 损失下，\(R(c \mid x) = 1 - P(c \mid x)\)，判定准则简化为： \[ h^*(x) = \arg\max_{c \in \mathcal{Y}} P(c \mid x) \]

两种建模策略： - 判别式模型：直接建模 \(P(c \mid x)\)（决策树、BP、SVM） - 生成式模型：先对联合分布 \(P(x,c)\) 建模

贝叶斯定理： \[ P(c \mid x) = \frac{P(c)P(x \mid c)}{P(x)} \] - \(P(c)\)：类先验概率（可用频率估计，大数定律） - \(P(x \mid c)\)：似然（类条件概率），涉及所有属性的联合概率，难以直接估计——样本空间大小 \(2^d\) 往往远大于训练样本数，“未被观测到” ≠ “概率为零”

7.2 极大似然估计（MLE）

思想：假定类条件概率具有确定的分布形式，用训练样本估计参数。

频率主义学派：参数是固定值，通过优化似然函数确定；贝叶斯学派：参数是随机变量，有先验分布。

似然：\(P(D_c \mid \theta_c) = \prod_{x \in D_c} P(x \mid \theta_c)\)，连乘易下溢 → 用对数似然： \[ LL(\theta_c) = \sum_{x \in D_c} \log P(x \mid \theta_c) \]

正态分布示例：若 \(p(x \mid c) \sim \mathcal{N}(\mu_c, \sigma_c^2)\)，则 \[ \hat{\mu}_c = \frac{1}{|D_c|}\sum_{x \in D_c} x,\quad \hat{\sigma}_c^2 = \frac{1}{|D_c|}\sum_{x \in D_c} (x - \hat{\mu}_c)(x - \hat{\mu}_c)^{\mathrm{T}} \]

即 MLE 得到均值 = 样本均值。注意：结果准确性严重依赖假设的分布形式是否符合真实分布。

7.3 朴素贝叶斯分类器

属性条件独立性假设：对已知类别，假设所有属性相互独立。

\[ h_{nb}(x) = \arg\max_{c \in \mathcal{Y}} P(c) \prod_{i=1}^{d} P(x_i \mid c) \]

概率估计（训练即计数）： - 先验：\(P(c) = \frac{|D_c|}{|D|}\) - 离散属性：\(P(x_i \mid c) = \frac{|D_{c,x_i}|}{|D_c|}\) - 连续属性：假定正态分布 \(p(x_i \mid c) \sim \mathcal{N}(\mu_{c,i}, \sigma_{c,i}^2)\) 代入密度函数

西瓜数据集 3.0 实例（测1：青绿/蜷缩/浊响/清晰/凹陷/硬滑/密度0.697/含糖0.460）： - \(P(\text{好瓜=是}) \approx 0.471\)，各条件概率连乘后总概率 ≈ 0.038；“好瓜=否” ≈ \(6.80 \times 10^{-5}\) → 判别为好瓜

拉普拉斯修正（处理“某个属性值未与某类同时出现”导致概率为 0 的问题）： \[ \hat{P}(c) = \frac{|D_c| + 1}{|D| + N},\quad \hat{P}(x_i \mid c) = \frac{|D_{c,x_i}| + 1}{|D_c| + N_i} \] 其中 \(N\) 为类别数，\(N_i\) 为第 \(i\) 个属性取值数。例：\(P_{\text{清脆|是}} = \frac{0+1}{8+3} \approx 0.091\)。

实质是假设属性值与类别均匀分布的先验；样本增多后影响可忽略。

使用方式：预计算查表（预测快）/ 懒惰学习（数据更替频繁）/ 增量学习（数据不断增加）。

7.4 半朴素贝叶斯分类器

独依赖估计（ODE）：假设每个属性在类别之外最多仅依赖一个其他属性： \[ P(c \mid x) \propto P(c) \prod_{i=1}^{d} P(x_i \mid c, pa_i) \]

SPODE：所有属性依赖同一个“超父”属性，用交叉验证确定超父。

TAN（树增强朴素贝叶斯）：基于最大带权生成树保留强相关依赖。步骤： 1. 计算属性对的条件互信息 \(I(x_i, x_j \mid y)\) 2. 以 \(I\) 为边权构建完全图 3. 求最大带权生成树，选根变量，边置有向 4. 加入类别结点 \(y\)，加 \(y \to\) 每个属性的边

AODE（平均独依赖估计）：将每个属性作为超父构建 SPODE，集成有足够样本支撑（\(|D_{c,x_i}| \geqslant m'\)）的： \[ P(c \mid x) \propto \sum_{\substack{i=1 \\ D_{c,x_i} \geqslant m'}}^{d} P(c, x_i) \prod_{j=1}^{d} P(x_j \mid c, x_i) \] 同样可用拉普拉斯修正计数估计，无需模型选择，支持预计算/懒惰学习/增量学习。

kDE：考虑 \(k\) 个父属性，但训练样本需求随 \(k\) 指数增长。

7.5 贝叶斯网

定义：贝叶斯网 \(B = \langle G, \Theta \rangle\)，\(G\) 为有向无环图（DAG），\(\Theta\) 为条件概率表（CPT）。

联合概率分布： \[ P_B(x_1, \dots, x_d) = \prod_{i=1}^{d} P_B(x_i \mid \pi_i) \]

结构（三种典型依赖关系）

  • 同父结构：给定父结点 \(x_1\)，\(x_3 \perp x_4 \mid x_1\)；但 \(x_1\) 未知时 \(x_3 \perp x_4\) 不成立
  • 顺序结构：\(y \perp z \mid x\)，但 \(y \perp z\) 不成立
  • V型结构（冲撞）：给定子结点 \(x_4\)，\(x_1\) 与 \(x_2\) 必不独立；\(x_4\) 未知时 \(x_1 \perp x_2\) 成立

D-分离与道德图：找出所有 V 型结构，父结点之间加无向边，所有边改无向 → 道德图。若 \(x\)、\(y\) 在道德图中被 \(z\) 分开（去除 \(z\) 后分属不同连通分支），则 \(x \perp y \mid z\)。

学习（评分搜索）

  • 评分函数：\(s(B \mid D) = f(\theta)|B| - LL(B \mid D)\)，其中 \(LL(B \mid D) = \sum_{i=1}^{m} \log P_B(x_i)\)
  • \(f(\theta)=1\) → AIC；\(f(\theta)=\frac12\log m\) → BIC
  • 结构固定时参数可直接用经验分布估计：\(\theta_{x_i|\pi_i} = \hat{P}_D(x_i \mid \pi_i)\)
  • 搜索最优结构是 NP 难问题 → 贪心法（每次调整一条边）/ 施加约束（限树形结构）

推断

  • 精确推断是 NP 难 → 用吉布斯采样（近似推断，马尔可夫链蒙特卡洛）
  • 采样 \(T\) 次，与查询 \(\mathbf{q}\) 一致的样本 \(n_q\) 个：\(P(\mathbf{Q}=\mathbf{q} \mid \mathbf{E}=\mathbf{e}) \simeq \frac{n_q}{T}\)
  • 马尔可夫链收敛慢；存在极端概率 0/1 时可能无平稳分布而给出错误结果

7.6 EM 算法

动机：训练样本存在隐变量 \(\mathbf{Z}\)（未观测变量），无法直接极大化 \(LL(\Theta \mid \mathbf{X}, \mathbf{Z}) = \ln P(\mathbf{X},\mathbf{Z} \mid \Theta)\)。

边际似然：对 \(\mathbf{Z}\) 求和取期望： \[ LL(\Theta \mid \mathbf{X}) = \ln \sum_{\mathbf{Z}} P(\mathbf{X}, \mathbf{Z} \mid \Theta) \]

EM 迭代： - E步：以当前参数 \(\Theta^t\) 推断隐变量分布，计算 \(Q(\Theta \mid \Theta^t) = \mathbb{E}_{\mathbf{Z}|\mathbf{X},\Theta^t} LL(\Theta \mid \mathbf{X},\mathbf{Z})\) - M步：\(\Theta^{t+1} = \arg\max_{\Theta} Q(\Theta \mid \Theta^t)\)

EM 可看作坐标下降法最大化对数似然下界；是非梯度优化方法（梯度法求和项随隐变量数指数增长）。典型应用：高斯混合模型（GMM）、k 均值聚类（9.4节）。

小结

概念 要点
贝叶斯决策 最小化条件风险，\(h^*\) 是理论上限
判别 vs 生成 直接建模 \(P(c\|x)\) vs 建模 \(P(x,c)\)
MLE 假设分布形式 → 对数似然估计参数
朴素贝叶斯 属性条件独立假设，训练即计数
拉普拉斯修正 避免概率为 0，\(+1\) 平滑
半朴素贝叶斯 ODE/SPODE/TAN/AODE/kDE
贝叶斯网 DAG + CPT，道德图判独立性
EM 算法 E步期望 + M步最大化，处理隐变量

《机器学习》自学日记（六）

第六章 支持向量机

6.1 间隔与支持向量

SVM 的核心思想：寻找具有“最大间隔”的划分超平面，使分类结果最鲁棒。

划分超平面： \[ w^{\mathrm{T}}x + b = 0 \] - \(w\) 为法向量，决定超平面方向；\(b\) 为位移项，决定与原点距离

样本点到超平面距离： \[ r = \frac{|w^{\mathrm{T}}x + b|}{\|w\|} \]

支持向量与间隔： - 令 \(y_i = +1\) 时 \(w^{\mathrm{T}}x_i + b \geqslant +1\)，\(y_i = -1\) 时 \(w^{\mathrm{T}}x_i + b \leqslant -1\) - 支持向量：使等号成立的训练样本点 - 间隔（margin）：两个异类支持向量到超平面距离之和 \[ \gamma = \frac{2}{\|w\|} \]

SVM 基本型： \[ \min_{w,b} \frac12 \|w\|^2 \quad \text{s.t.} \quad y_i(w^{\mathrm{T}}x_i + b) \geqslant 1,\; i = 1,\dots,m \]

6.2 对偶问题

利用拉格朗日乘子法将原问题转化为对偶问题：

拉格朗日函数： \[ L(w,b,\alpha) = \frac12 \|w\|^2 + \sum_{i=1}^m \alpha_i (1 - y_i(w^{\mathrm{T}}x_i + b)) \]

令偏导为零得： \[ w = \sum_{i=1}^m \alpha_i y_i x_i,\quad 0 = \sum_{i=1}^m \alpha_i y_i \]

对偶问题： \[ \max_{\alpha} \sum_{i=1}^m \alpha_i - \frac12 \sum_{i=1}^m \sum_{j=1}^m \alpha_i \alpha_j y_i y_j x_i^{\mathrm{T}}x_j \] \[ \text{s.t.} \quad \sum_{i=1}^m \alpha_i y_i = 0,\quad \alpha_i \geqslant 0 \]

KKT 条件： \[ \begin{cases} \alpha_i \geqslant 0 \\ y_i f(x_i) - 1 \geqslant 0 \\ \alpha_i (y_i f(x_i) - 1) = 0 \end{cases} \]

核心结论：最终模型仅与 \(\alpha_i > 0\) 的支持向量有关，非支持向量对模型无影响。

SMO 算法（Sequential Minimal Optimization）： 1. 每次选取两个变量 \(\alpha_i, \alpha_j\)，固定其余参数 2. 利用约束 \(\alpha_i y_i + \alpha_j y_j = c\) 消元，得到关于 \(\alpha_i\) 的单变量二次规划（有闭式解） 3. 变量选择启发式：找违背 KKT 程度最大的 + 间隔最大的对应样本

偏移项 \(b\) 的求解：对所有支持向量求解后取平均： \[ b = \frac{1}{|S|} \sum_{s \in S} \left(y_s - \sum_{i \in S} \alpha_i y_i x_i^{\mathrm{T}} x_s\right) \]

6.3 核函数

动机：现实任务中原始空间可能不存在线性可分超平面 → 映射到更高维特征空间。

核技巧（kernel trick）：不显式计算 \(\phi(x_i)^{\mathrm{T}}\phi(x_j)\)，而是通过核函数直接计算： \[ \kappa(x_i, x_j) = \langle \phi(x_i), \phi(x_j) \rangle = \phi(x_i)^{\mathrm{T}}\phi(x_j) \]

常用核函数：

名称 表达式 参数
线性核 \(x_i^{\mathrm{T}}x_j\) —
多项式核 \((x_i^{\mathrm{T}}x_j)^d\) \(d \geqslant 1\) 次数
高斯核（RBF） \(\exp\left(-\dfrac{\|x_i - x_j\|^2}{2\sigma^2}\right)\) \(\sigma > 0\) 带宽
拉普拉斯核 \(\exp\left(-\dfrac{\|x_i - x_j\|}{\sigma}\right)\) \(\sigma > 0\)
Sigmoid 核 \(\tanh(\beta x_i^{\mathrm{T}}x_j + \theta)\) \(\beta > 0, \theta < 0\)

核函数判定（Mercer 定理）：对称函数 \(\kappa\) 是核函数 \(\iff\) 对任意数据，核矩阵 \(\mathbf{K}\) 半正定。

核函数组合： - 线性组合 \(\gamma_1\kappa_1 + \gamma_2\kappa_2\) - 直积 \(\kappa_1 \otimes \kappa_2(x,z) = \kappa_1(x,z)\kappa_2(x,z)\) - 函数缩放 \(\kappa(x,z) = g(x)\kappa_1(x,z)g(z)\)

核函数选择是 SVM 的最大变数。

6.4 软间隔与正则化

硬间隔：要求所有样本满足 \(y_i(w^{\mathrm{T}}x_i + b) \geqslant 1\)（线性可分假设） 软间隔：允许部分样本不满足约束，引入损失项

优化目标： \[ \min_{w,b} \frac12 \|w\|^2 + C \sum_{i=1}^m \ell_{0/1}\big(y_i(w^{\mathrm{T}}x_i + b) - 1\big) \]

替代损失函数（\(\ell_{0/1}\) 非凸、不连续，需用凸替代）：

名称 表达式
Hinge 损失 \(\max(0, 1 - z)\)
指数损失 \(\exp(-z)\)
对率损失 \(\log(1 + \exp(-z))\)

软间隔 SVM（采用 Hinge 损失）： \[ \min_{w,b,\xi_i} \frac12 \|w\|^2 + C \sum_{i=1}^m \xi_i \] \[ \text{s.t.} \quad y_i(w^{\mathrm{T}}x_i + b) \geqslant 1 - \xi_i,\quad \xi_i \geqslant 0 \]

对偶问题：与硬间隔的唯一差别是 \(\alpha_i\) 加了上界： \[ 0 \leqslant \alpha_i \leqslant C \]

结构风险 vs 经验风险： \[ \min_f \Omega(f) + C \sum_{i=1}^m \ell(f(x_i), y_i) \] - \(\Omega(f)\)：结构风险（正则化项），表达模型性质偏好 - \(\sum \ell\)：经验风险，描述与训练数据契合程度 - \(L_2\) 范数使 \(w\) 分量稠密，\(L_0\)/\(L_1\) 范数使分量稀疏

6.5 支持向量回归（SVR）

\(\epsilon\)-不敏感损失：允许 \(f(x)\) 与 \(y\) 间最多有 \(\epsilon\) 偏差，落入 \(\epsilon\)-间隔带的样本不计损失： \[ \ell_{\epsilon}(z) = \begin{cases} 0, & |z| \leqslant \epsilon \\ |z| - \epsilon, & \text{otherwise} \end{cases} \]

SVR 优化问题： \[ \min_{w,b} \frac12 \|w\|^2 + C \sum_{i=1}^m \ell_{\epsilon}(f(x_i) - y_i) \]

引入双松弛变量 \(\xi_i, \hat{\xi}_i\) 后转化为凸二次规划，对偶解： \[ f(x) = \sum_{i=1}^m (\hat{\alpha}_i - \alpha_i) \kappa(x, x_i) + b \]

SVR 的支持向量是落在 \(\epsilon\)-间隔带之外的样本，解仍具稀疏性。

6.6 核方法

表示定理（Representer Theorem）：对于任何单调递增 \(\Omega\) 和任何非负损失 \(\ell\)，优化问题 \[ \min_{h \in \mathbb{H}} \Omega(\|h\|_{\mathbb{H}}) + \ell(h(x_1),\dots,h(x_m)) \] 的最优解总可写成核函数的线性组合： \[ h^*(x) = \sum_{i=1}^m \alpha_i \kappa(x, x_i) \]

KLDA（核线性判别分析）：在核映射后的特征空间中执行 LDA，通过表示定理转化为核矩阵上的广义 Rayleigh 商问题。

小结

概念 要点
间隔 \(\gamma = 2/\|w\|\)，SVM 最大化间隔
对偶 拉格朗日乘子法 → 支持向量决定模型
SMO 每次选两个变量，闭式更新
核技巧 \(\kappa(x_i,x_j) = \phi(x_i)^{\mathrm{T}}\phi(x_j)\)，隐式高维映射
软间隔 引入 \(\xi_i\) 和 \(C\)，\(\alpha_i\) 增加 \(C\) 上界
SVR \(\epsilon\)-不敏感损失，双松弛变量
核方法 表示定理 → 任何核化模型的解是核函数线性组合

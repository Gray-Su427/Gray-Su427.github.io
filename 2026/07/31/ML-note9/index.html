《机器学习》自学日记（九）

第九章 聚类

9.1 聚类任务

无监督学习：训练样本无标记信息，通过学习揭示数据内在性质与规律。

聚类：将数据集划分为若干不相交子集——簇。簇对应潜在概念（语义需使用者命名），事先未知。

形式化：样本集 \(D = \{x_1, x_2, \dots, x_m\}\)，\(x_i\) 为 \(n\) 维特征向量，划分为 \(k\) 个不相交簇 \(\{C_1, \dots, C_k\}\)，\(C_{l'} \cap_{l \neq l'} C_l = \emptyset\) 且 \(D = \bigcup C_l\)。\(\lambda_j\) 为样本 \(x_j\) 的簇标记。

聚类两大用途：① 单独过程，发现数据内在分布结构；② 作为分类等任务的前驱（先聚类定义类别，再训练分类器）。

9.2 性能度量（有效性指标）

目标：“物以类聚”——簇内相似度高、簇间相似度低。

外部指标（与参考模型 \(C^*\) 比较）

两两样本对定义（\(i < j\)，\(a + b + c + d = m(m-1)/2\)）： - \(a = |SS|\)：\(C\) 同簇且 \(C^*\) 同簇 - \(b = |SD|\)：\(C\) 同簇但 \(C^*\) 不同簇 - \(c = |DS|\)：\(C\) 不同簇但 \(C^*\) 同簇 - \(d = |DD|\)：\(C\) 与 \(C^*\) 均不同簇

常用指标（均 \([0,1]\)，越大越好）： \[ \mathrm{JC} = \frac{a}{a+b+c},\quad \mathrm{FMI} = \sqrt{\frac{a}{a+b} \cdot \frac{a}{a+c}},\quad \mathrm{RI} = \frac{2(a+d)}{m(m-1)} \]

内部指标（不依赖参考模型）

簇内距离定义： \[ \operatorname{avg}(C) = \frac{2}{|C|(|C|-1)} \sum_{i<j} \operatorname{dist}(x_i, x_j),\quad \operatorname{diam}(C) = \max_{i<j} \operatorname{dist}(x_i, x_j) \]

簇间距离： \[ d_{\min}(C_i, C_j) = \min \operatorname{dist}(x_i, x_j),\quad d_{\mathrm{cen}}(C_i, C_j) = \operatorname{dist}(\mu_i, \mu_j) \]

  • DB指数（DBI）：越小越好 \[ \mathrm{DBI} = \frac{1}{k} \sum_{i=1}^{k} \max_{j \neq i} \left( \frac{\operatorname{avg}(C_i) + \operatorname{avg}(C_j)}{d_{\mathrm{cen}}(C_i, C_j)} \right) \]
  • Dunn指数（DI）：越大越好 \[ \mathrm{DI} = \min_{1 \leqslant i \leqslant k} \left\{ \min_{j \neq i} \left( \frac{d_{\min}(C_i, C_j)}{\max_{1 \leqslant l \leqslant k} \operatorname{diam}(C_l)} \right) \right\} \]

9.3 距离计算

距离度量四性质：非负性、同一性（\(\operatorname{dist}(x_i,x_j)=0 \iff x_i = x_j\)）、对称性、直递性（三角不等式）。

闵可夫斯基距离： \[ \operatorname{dist}_{\mathrm{mk}}(x_i, x_j) = \left( \sum_{u=1}^{n} |x_{iu} - x_{ju}|^{p} \right)^{\frac{1}{p}}, \quad p \geqslant 1 \] - \(p=2\)：欧氏距离；\(p=1\)：曼哈顿距离

属性类型：关键是是否有序关系——有序属性可直接算距离（如 \(\{1,2,3\}\)）；无序属性（如 \(\{\)飞机,火车,轮船\(\}\)）用 VDM： \[ \operatorname{VDM}_p(a, b) = \sum_{i=1}^{k} \left| \frac{m_{u,a,i}}{m_{u,a}} - \frac{m_{u,b,i}}{m_{u,b}} \right|^{p} \] （\(m_{u,a,i}\) 为第 \(i\) 簇中属性 \(u\) 取 \(a\) 的样本数）

混合属性：闵可夫斯基距离 + VDM 结合（MinkovDM）；属性重要性不同时用加权距离。

非度量距离：相似度度量不要求满足直递性（例：“人”“马”都与人马相似，但彼此不相似），如图像检索中的部分相似性。距离计算式也可通过距离度量学习从数据中习得。

9.4 原型聚类

9.4.1 k均值算法

最小化平方误差： \[ E = \sum_{i=1}^{k} \sum_{x \in C_i} \|x - \mu_i\|_2^2 \] - 最优解需穷举所有划分，NP难 → 贪心迭代：随机初始化均值向量 → 样本划入最近簇 → 重算均值，直至簇划分不变 - 西瓜数据集 4.0 示例（\(k=3\)，初值 \(x_6, x_{12}, x_{27}\)）：\(x_1\) 距 \(\mu_1,\mu_2,\mu_3\) 为 \(0.369, 0.506, 0.166\) → 划入 \(C_3\)；第五轮迭代结果与第四轮相同即停止

9.4.2 学习向量量化（LVQ）

与 k 均值类似找原型向量，但利用样本类别标记辅助聚类（监督信息）。

迭代规则：随机选样本 \(x_j\)，找最近原型 \(p_{i^*}\)： - 类别标记相同 → 靠近：\(p' = p_{i^*} + \eta(x_j - p_{i^*})\)，距离变为 \((1-\eta)\|p_{i^*} - x_j\|_2\) - 类别标记不同 → 远离：距离变为 \((1+\eta)\|p_{i^*} - x_j\|_2\)

原型向量划分样本空间形成 Voronoi 剖分： \[ R_i = \{x \mid \|x - p_i\|_2 \leqslant \|x - p_{i'}\|_2,\ i' \neq i\} \]

9.4.3 高斯混合聚类（Mixture-of-Gaussian）

用概率模型表达原型。多元高斯分布 \(p(x \mid \mu, \Sigma)\)，高斯混合分布： \[ p_M(x) = \sum_{i=1}^{k} \alpha_i \cdot p(x \mid \mu_i, \Sigma_i) \]

生成过程：先按 \(\alpha_i\) 选混合成分，再按该成分的密度采样。

后验概率（\(x_j\) 由第 \(i\) 个成分生成）： \[ \gamma_{ji} = p_M(z_j = i \mid x_j) = \frac{\alpha_i \cdot p(x_j \mid \mu_i, \Sigma_i)}{\sum_{l=1}^{k} \alpha_l \cdot p(x_j \mid \mu_l, \Sigma_l)} \]

簇标记：\(\lambda_j = \arg\max_i \gamma_{ji}\)。

参数求解（EM 算法）：最大化对数似然 \(LL(D) = \sum_j \ln \left( \sum_i \alpha_i p(x_j \mid \mu_i, \Sigma_i) \right)\)，令对各参数偏导为 0： \[ \mu_i = \frac{\sum_j \gamma_{ji} x_j}{\sum_j \gamma_{ji}},\quad \Sigma_i = \frac{\sum_j \gamma_{ji} (x_j - \mu_i)(x_j - \mu_i)^{\mathrm{T}}}{\sum_j \gamma_{ji}},\quad \alpha_i = \frac{1}{m} \sum_{j=1}^{m} \gamma_{ji} \]

E步算后验 \(\gamma_{ji}\)，M步更新参数，迭代至似然增益很小。西瓜示例（\(k=3\)）：初始 \(\alpha_i = \frac13\)，\(x_1\) 的 \(\gamma_{11},\gamma_{12},\gamma_{13} = 0.219, 0.404, 0.377\)。

9.5 密度聚类（DBSCAN）

基于邻域参数 \((\epsilon, MinPts)\) 刻画样本分布紧密程度。

核心概念： - \(\epsilon\)-邻域：\(N_\epsilon(x_j) = \{x_i \mid \operatorname{dist}(x_i, x_j) \leqslant \epsilon\}\) - 核心对象：\(|N_\epsilon(x_j)| \geqslant MinPts\) - 密度直达：\(x_j \in N_\epsilon(x_i)\) 且 \(x_i\) 为核心对象 - 密度可达：存在序列 \(p_1, \dots, p_n\) 使 \(p_{t+1}\) 由 \(p_t\) 密度直达 - 密度相连：存在 \(x_k\) 使 \(x_i\)、\(x_j\) 均由 \(x_k\) 密度可达

簇的定义：由密度可达导出的最大密度相连样本集合，满足连接性（簇内两两密度相连）与最大性（由簇内核心对象可达的样本必在簇内）。

算法：找出所有核心对象 → 任选核心对象为种子，扩展出所有密度可达样本成簇 → 移除簇内核心对象，重复直到 \(O\) 为空。其余样本为噪声。

西瓜示例（\(\epsilon=0.11, MinPts=5\)）：核心对象集合 13 个，依次生成 \(C_1\)（9样本）、\(C_2\)、\(C_3\)、\(C_4\)。

9.6 层次聚类（AGNES）

自底向上聚合：初始每个样本一个簇，逐步合并距离最近的两个簇，直到达到预设簇数。

簇间距离： - 最小距离 \(d_{\min}\)（最近样本决定）→ 单链接 - 最大距离 \(d_{\max}\)（最远样本决定）→ 全链接 - 平均距离 \(d_{\operatorname{avg}} = \frac{1}{|C_i||C_j|}\sum_{x \in C_i} \sum_{z \in C_j} \operatorname{dist}(x, z)\) → 均链接

西瓜示例：合并到 \(k=1\) 得树状图，在特定层次分割可得任意簇数的划分（如虚线分割得 7 簇）。

小结

概念 要点
外部指标 JC / FMI / RI，与参考模型比较
内部指标 DBI（越小越好）/ DI（越大越好）
距离度量 四性质；闵可夫斯基族；VDM 处理无序属性
k均值 最小化 \(E\)，贪心迭代，NP难，凸簇效果好
LVQ 利用类别标记，原型靠近/远离样本
高斯混合 概率模型 + EM 求解，软聚类
DBSCAN 密度相连最大集合，可处理噪声与非凸簇
AGNES 自底向上合并，单/全/均链接，树状图

《机器学习》自学日记（八）

第八章 集成学习

8.1 个体与集成

集成学习：构建并结合多个学习器完成学习任务（多分类器系统/基于委员会的学习）。

  • 同质集成：个体学习器类型相同，称基学习器（如决策树集成）
  • 异质集成：个体学习器类型不同，称组件学习器
  • 弱学习器：泛化性能略优于随机猜测（二分类精度略高于 50%）

好而不同：好的集成要求个体学习器“好而不同”——准确性 + 多样性（图8.2示例：三个 66.6% 精度的分类器投票后可达 100%）。

理论依据（Hoeffding 不等式）：若 \(T\) 个基分类器错误率 \(\epsilon\) 相互独立，则集成错误率 \[ P(H(x) \neq f(x)) \leqslant \exp\left(-\frac12 T(1-2\epsilon)^2\right) \] 即错误率随 \(T\) 指数下降。但现实中基学习器误差不可能独立——准确性与多样性存在冲突，这正是集成学习的核心难点。

两大流派： - 序列化方法（强依赖，串行）：Boosting - 并行化方法（无强依赖，同时生成）：Bagging、随机森林

8.2 Boosting（以 AdaBoost 为例）

工作机制：从初始训练集训练基学习器 → 根据表现调整样本分布（错样本受更多关注）→ 训练下一个 → 加权结合。

加性模型视角：\(H(x) = \sum_{t=1}^{T} \alpha_t h_t(x)\)，最小化指数损失： \[ \ell_{\mathrm{exp}}(H \mid \mathcal{D}) = \mathbb{E}_{x \sim \mathcal{D}}[e^{-f(x)H(x)}] \]

为什么用指数损失：最小化指数损失时 \(H(x) = \frac12 \ln \frac{P(f=1|x)}{P(f=-1|x)}\)，则 \(\mathrm{sign}(H(x)) = \arg\max_y P(f(x)=y \mid x)\) 达到贝叶斯最优错误率——指数损失是 0/1 损失的一致替代函数（连续可微）。

分类器权重推导：令 \(\alpha_t h_t\) 最小化 \(\ell_{\mathrm{exp}}\) 得 \[ \alpha_t = \frac12 \ln\left(\frac{1 - \epsilon_t}{\epsilon_t}\right) \]

样本分布更新： \[ \mathcal{D}_{t+1}(x) = \mathcal{D}_t(x) \cdot e^{-f(x)\alpha_t h_t(x)} \cdot \frac{\mathbb{E}[e^{-f(x)H_{t-1}(x)}]}{\mathbb{E}[e^{-f(x)H_t(x)}]} \]

实施细节： - 重赋权法（可接受带权样本的算法）/ 重采样法（不可接受的算法） - 每轮检查基学习器是否优于随机猜测（误差 < 0.5），否则丢弃并停止；重采样法可“重启动”避免过早停止

偏差-方差视角：Boosting 主要降低偏差，能基于弱学习器构建强集成。

8.3 Bagging 与随机森林

Bagging

动机：采样产生多个有交叠的训练子集 → 训练差异大的基学习器（完全不相交的子集会使基学习器太差）。

流程：自助采样法（bootstrap）采样 \(T\) 个含 \(m\) 个样本的训练集 → 每个训练一个基学习器 → 分类用简单投票、回归用简单平均。

性质： - 每个采样集含初始集约 63.2% 的样本（不重复概率 \(1 - e^{-1}\)） - 剩余 36.8% 可用作包外估计（OOB）验证集： \[ \epsilon^{oob} = \frac{1}{|D|}\sum_{(x,y) \in D} \mathbb{I}(H^{oob}(x) \neq y) \] 只统计未使用 \(x\) 训练的基学习器的投票 - 计算复杂度与单学习器同阶，高效；适用于多分类、回归 - 偏差-方差视角：Bagging 主要降低方差，对不剪枝决策树、神经网络等易受样本扰动的学习器效果明显

随机森林（RF）

定义：Bagging + 决策树 + 随机属性选择——每个结点先从属性集随机选 \(k\) 个属性的子集，再从中选最优划分属性。

  • \(k = d\) 退化为传统决策树；\(k = 1\) 随机选一个；推荐 \(k = \log_2 d\)
  • 多样性来源：样本扰动 + 属性扰动（Bagging 只有样本扰动）
  • 起始性能较差（单学习器时），随数量增加收敛到更低泛化误差
  • 训练效率高于 Bagging：随机型决策树只需考察 \(k\) 个属性，而非全部

8.4 结合策略

结合的三大好处（Dietterich）： 1. 统计：多个假设在训练集上等优，结合减小误选风险 2. 计算：降低陷入糟糕局部极小的风险 3. 表示：扩大假设空间，可能学得更优近似

平均法（回归）

  • 简单平均：\(H(x) = \frac1T \sum_{i=1}^{T} h_i(x)\)
  • 加权平均：\(H(x) = \sum_{i=1}^{T} w_i h_i(x)\)，\(w_i \geqslant 0, \sum w_i = 1\)
  • 权重从数据学出易过拟合：性能相差大时用加权平均，相近时用简单平均

投票法（分类）

  • 绝对多数投票：票数过半才预测，否则拒绝（可靠性要求高时有用）
  • 相对多数投票：得票最多者胜，平票随机选
  • 加权投票：按 \(w_i\) 加权求和
  • 硬投票（类标记 0/1）vs 软投票（类概率）；不同类型输出不能混用；SVM 间隔需 Platt 缩放等校准后才能当类概率用；软投票往往优于硬投票

学习法（Stacking）

  • 初级学习器：个体学习器；次级学习器/元学习器：用于结合的学习器
  • 次级训练集用交叉验证产生（避免直接用初级学习器训练集导致过拟合）：第 \(j\) 折的样本 \(x_i\) 的次级样例特征为 \(z_i = (h_1^{(j)}(x_i); \dots; h_T^{(j)}(x_i))\)
  • 效果较好配置：初级学习器输出类概率作输入 + 多响应线性回归（MLR）作次级算法
  • BMA（贝叶斯模型平均）理论上在模型正确时优于 Stacking，但实际中 Stacking 更鲁棒

8.5 多样性

误差-分歧分解（回归任务）

  • 个体分歧：\(A(h_i \mid x) = (h_i(x) - H(x))^2\)
  • 集成泛化误差：\(E = \overline{E} - \overline{A}\)（\(\overline{E}\) 个体误差加权均值，\(\overline{A}\) 加权分歧）
  • 含义：个体准确性越高、多样性越大，集成越好；但 \(\overline{A}\) 不可直接优化（构造后才知道），且只适用于回归

多样性度量（两两列联表）

度量 公式 值域/含义
不合度量 \(d_{ij} = \frac{b+c}{m}\) \([0,1]\) 越大越多样
相关系数 \(\rho_{ij} = \frac{ad-bc}{\sqrt{(a+b)(a+c)(c+d)(b+d)}}\) \([-1,1]\)
Q-统计量 \(Q_{ij} = \frac{ad-bc}{ad+bc}\) 与 \(\rho\) 同号，\(|Q| \leqslant |\rho|\)
\(\kappa\)-统计量 \(\kappa = \frac{p_1 - p_2}{1 - p_2}\) \(=1\) 完全一致，\(=0\) 偶然一致

\(\kappa\)-误差图：横轴 \(\kappa\)，纵轴平均误差；越靠右上方多样性越小、准确性越低。

多样性增强（引入随机性）

  1. 数据样本扰动：自助采样/序列采样。对决策树、神经网络等不稳定基学习器有效；对线性学习器、SVM、朴素贝叶斯、kNN 等稳定基学习器无效
  2. 输入属性扰动：随机子空间算法，从属性集抽取子集训练；冗余属性多时效果好
  3. 输出表示扰动：翻转法（改类标记）、输出调制法（分类→回归）、ECOC（多分类拆解为二分类）
  4. 算法参数扰动：随机设置神经网络隐层神经元数、初始权值等；负相关法用正则项强制差异

可组合使用：随机森林 = 样本扰动 + 属性扰动。

小结

概念 要点
好而不同 准确性 + 多样性，二者冲突是核心难点
AdaBoost 加性模型 + 指数损失，\(\alpha_t = \frac12\ln\frac{1-\epsilon_t}{\epsilon_t}\)，降低偏差
Bagging 自助采样 + 投票/平均，63.2% 样本，包外估计，降低方差
随机森林 样本扰动 + 属性扰动（\(k = \log_2 d\)），训练更快
结合策略 平均法 / 投票法（硬/软）/ Stacking（元学习器）
误差-分歧分解 \(E = \overline{E} - \overline{A}\)，只适用回归
多样性度量 不合度量 / 相关系数 / Q统计量 / \(\kappa\)
多样性增强 样本 / 属性 / 输出 / 参数 四种扰动

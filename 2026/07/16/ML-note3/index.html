《机器学习》自学日记（三）

第三章 线性模型

3.1 基本形式

线性模型：试图学得一个通过属性的线性组合来进行预测的函数

\[ f(\pmb{x}) = \pmb{w}^{\mathrm{T}}\pmb{x} + b \]

  • \(\pmb{w} = (w_1;w_2;\dots;w_d)\) 直观表达了各属性在预测中的重要性
  • 线性模型可解释性强，例如 \(f_{\text{好瓜}}(x) = 0.2\cdot x_{\text{色泽}} + 0.5\cdot x_{\text{根蒂}} + 0.3\cdot x_{\text{敲声}} + 1\)
  • 许多非线性模型可通过引入层级结构或高维映射得到

3.2 线性回归

一元线性回归

给定 \(D = \{(x_i,y_i)\}_{i=1}^m\)，试图学得 \(f(x_i) = wx_i + b\)，使 \(f(x_i) \simeq y_i\)。

最小二乘法：基于均方误差最小化求解 \(w,b\)

\[ (w^*,b^*) = \arg\min_{(w,b)} \sum_{i=1}^m (y_i - wx_i - b)^2 \]

\(E_{(w,b)}\) 是凸函数，令导数为零得闭式解：

\[ w = \frac{\sum_{i=1}^m y_i(x_i - \bar{x})}{\sum_{i=1}^m x_i^2 - \frac1m (\sum_{i=1}^m x_i)^2}, \quad b = \frac1m \sum_{i=1}^m (y_i - wx_i) \]

其中 \(\bar{x} = \frac1m \sum_{i=1}^m x_i\)。

多元线性回归

样本由 \(d\) 个属性描述，将 \(\hat{\pmb{w}} = (\pmb{w};b)\) 吸收入向量形式，数据集表示为 \(m\times(d+1)\) 的矩阵 \(\mathbf{X}\)。

目标函数：

\[ \hat{\pmb{w}}^* = \arg\min_{\hat{\pmb{w}}} (\pmb{y} - \mathbf{X}\hat{\pmb{w}})^{\mathrm{T}}(\pmb{y} - \mathbf{X}\hat{\pmb{w}}) \]

令导数为零，当 \(\mathbf{X}^{\mathrm{T}}\mathbf{X}\) 满秩时：

\[ \hat{\pmb{w}}^* = (\mathbf{X}^{\mathrm{T}}\mathbf{X})^{-1}\mathbf{X}^{\mathrm{T}}\pmb{y} \]

若 \(\mathbf{X}^{\mathrm{T}}\mathbf{X}\) 不满秩（如变量数超过样例数），则引入正则化项由归纳偏好决定解。

广义线性模型

对数线性回归： \[ \ln y = \pmb{w}^{\mathrm{T}}x + b \quad\Rightarrow\quad y = e^{\pmb{w}^{\mathrm{T}}x + b} \]

广义线性模型： \[ y = g^{-1}(\pmb{w}^{\mathrm{T}}x + b) \]

其中 \(g(\cdot)\) 称为联系函数（link function）。对数线性回归是其特例（\(g(\cdot) = \ln(\cdot)\)）。

3.3 对数几率回归

用于二分类任务，输出 \(y \in \{0,1\}\)。

单位阶跃函数不连续，无法直接使用。用对数几率函数（Sigmoid）替代：

\[ y = \frac{1}{1 + e^{-z}}, \quad z = \pmb{w}^{\mathrm{T}}x + b \]

变换得：

\[ \ln \frac{y}{1-y} = \pmb{w}^{\mathrm{T}}x + b \]

  • \(\frac{y}{1-y}\) 称为几率（odds），反映正例相对可能性
  • \(\ln \frac{y}{1-y}\) 称为对数几率（log odds / logit）

特点：直接对分类可能性建模，无需假设数据分布；输出近似概率；目标函数是凸函数。

参数求解（极大似然法）

令 \(\pmb{\beta} = (\pmb{w};b)\), \(\hat{\pmb{x}} = (x;1)\)，最大化对数似然等价于最小化：

\[ \ell(\pmb{\beta}) = \sum_{i=1}^m \left(-y_i\pmb{\beta}^{\mathrm{T}}\hat{\pmb{x}}_i + \ln(1 + e^{\pmb{\beta}^{\mathrm{T}}\hat{\pmb{x}}_i})\right) \]

该函数是凸函数，可用梯度下降法、牛顿法等求解。牛顿法迭代公式：

\[ \pmb{\beta}^{t+1} = \pmb{\beta}^t - \left(\frac{\partial^2\ell(\pmb{\beta})}{\partial\pmb{\beta}\partial\pmb{\beta}^{\mathrm{T}}}\right)^{-1} \frac{\partial\ell(\pmb{\beta})}{\partial\pmb{\beta}} \]

3.4 线性判别分析（LDA）

核心思想：将样例投影到一条直线上，使同类投影点尽可能接近、异类投影点尽可能远离。

Fisher判别分析：LDA在二分类上的别称。

目标函数

定义类内散度矩阵 \(\mathbf{S}_w\) 和类间散度矩阵 \(\mathbf{S}_b\)：

\[ \mathbf{S}_w = \Sigma_0 + \Sigma_1 = \sum_{\pmb{x}\in X_0}(\pmb{x}-\mu_0)(\pmb{x}-\mu_0)^{\mathrm{T}} + \sum_{\pmb{x}\in X_1}(\pmb{x}-\mu_1)(\pmb{x}-\mu_1)^{\mathrm{T}} \]

\[ \mathbf{S}_b = (\mu_0 - \mu_1)(\mu_0 - \mu_1)^{\mathrm{T}} \]

最大化广义瑞利商：

\[ J = \frac{\pmb{w}^{\mathrm{T}}\mathbf{S}_b\pmb{w}}{\pmb{w}^{\mathrm{T}}\mathbf{S}_w\pmb{w}} \]

解为：

\[ \pmb{w} = \mathbf{S}_w^{-1}(\mu_0 - \mu_1) \]

多分类LDA

将样本投影到 \(N-1\) 维空间（\(N\) 为类别数），最大化：

\[ \max_{\mathbf{W}} \frac{\operatorname{tr}(\mathbf{W}^{\mathrm{T}}\mathbf{S}_b\mathbf{W})}{\operatorname{tr}(\mathbf{W}^{\mathrm{T}}\mathbf{S}_w\mathbf{W})} \]

\(\mathbf{W}\) 的闭式解是 \(\mathbf{S}_w^{-1}\mathbf{S}_b\) 的 \(N-1\) 个最大广义特征值对应的特征向量。LDA 也常被视为一种监督降维技术。

3.5 多分类学习

基本思路：拆解法（将多分类拆为多个二分类任务）。

策略 方法 分类器数量 优缺点
OvO（一对一） 每两类配对训练一个分类器 \(N(N-1)/2\) 训练快（每类只用两个类数据），测试慢
OvR（一对其余） 每类 vs 其余 \(N\) 训练慢（用全部数据），测试快
MvM（多对多） 若干类为正，若干为反 由编码决定 需特殊构造，如ECOC

ECOC（纠错输出码）： - 编码：对 \(N\) 个类别做 \(M\) 次划分，训练 \(M\) 个分类器 - 解码：\(M\) 个分类器预测结果组成编码，与各类别编码比较距离 - 编码越长，纠错能力越强，但代价也越大 - 对同等码长，各类编码距离越远纠错越强（找到最优编码是NP难）

3.6 类别不平衡问题

问题：不同类别训练样例数目差别很大（如998反例:2正例）。

基本策略——再缩放：

\[ \frac{y'}{1-y'} = \frac{y}{1-y} \times \frac{m^-}{m^+} \]

三种实现方式：

方法 操作 代表算法 注意
欠采样 去除反例 EasyEnsemble 可能丢失重要信息
过采样 增加正例 SMOTE（插值生成） 不能简单重复采样（会过拟合）
阈值移动 不改数据，调整决策阈值 — 直接嵌入再缩放到决策过程

再缩放也是代价敏感学习的基础，将 \(\frac{m^-}{m^+}\) 替换为 \(\frac{cost^+}{cost^-}\) 即可。

小结

第三章介绍了线性模型这一基础而重要的模型族：

  1. 线性回归：最小二乘法求最优参数，广义线性模型扩展表达能力
  2. 对数几率回归：用 Sigmoid 函数将线性模型用于分类，极大似然法求解
  3. 线性判别分析：通过最大化类间/类内散度比，实现分类与降维
  4. 多分类学习：OvO/OvR/MvM 拆分策略，ECOC 编码纠错
  5. 类别不平衡：再缩放思想及其三种实现

线性模型虽形式简单，但蕴含了正则化、似然函数、降维投影等许多核心思想，是后续复杂模型的基础。

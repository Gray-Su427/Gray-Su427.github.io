《机器学习》自学日记（十）

第十章 降维与度量学习

10.1 k近邻学习

kNN：给定测试样本，基于距离度量找出训练集中最靠近的 \(k\) 个样本，据此预测——分类用投票法，回归用平均法，也可距离加权。

  • 懒惰学习：训练阶段仅保存样本（零训练开销），测试时才处理；对应的急切学习在训练阶段就学习。
  • \(k\) 取值与距离计算方式都会显著影响分类结果。

最近邻分类器（1NN）泛化错误率上界：设 \(x\) 的最近邻为 \(z\)，则 \[ P(\mathrm{err}) = 1 - \sum_{c \in \mathcal{Y}} P(c \mid x)P(c \mid z) \lesssim 2 \times (1 - P(c^{*} \mid x)) \] 即 1NN 的泛化错误率不超过贝叶斯最优分类器错误率的两倍（需密采样假设）。

10.2 低维嵌入

密采样困难 → 维数灾难：属性维数 20 时需 \(10^{60}\) 样本才能密采样；高维还带来距离计算困难。

降维动机：数据虽高维，但与任务相关的可能是某个低维分布——低维嵌入。降维后样本密度提高、距离计算容易。

多维缩放（MDS）

目标：\(d'\) 维空间中样本欧氏距离等于原始空间距离，即 \(\|z_i - z_j\| = \operatorname{dist}_{ij}\)。

由内积矩阵 \(B = Z^{\mathrm{T}}Z\)（中心化后行、列和均为 0）： \[ \operatorname{dist}_{ij}^2 = b_{ii} + b_{jj} - 2b_{ij} \] 结合 \(\sum_i \operatorname{dist}_{ij}^2 = \operatorname{tr}(B) + m b_{jj}\) 等关系可反解： \[ b_{ij} = -\frac{1}{2}\left( \operatorname{dist}_{ij}^2 - \operatorname{dist}_{i\cdot}^2 - \operatorname{dist}_{\cdot j}^2 + \operatorname{dist}_{\cdot\cdot}^2 \right) \] 对 \(B\) 特征值分解：\(B = V\Lambda V^{\mathrm{T}}\)，取 \(d'\) 个最大特征值得 \(Z = \tilde{\Lambda}^{1/2}\tilde{V}^{\mathrm{T}} \in \mathbb{R}^{d' \times m}\)。

线性降维一般形式：\(z = W^{\mathrm{T}}x\)，\(W \in \mathbb{R}^{d \times d'}\) 为正交变换矩阵，新空间属性是原属性的线性组合；不同方法对 \(W\) 施加不同约束。

10.3 主成分分析（PCA）

对超平面的要求两条等价性质： - 最近重构性：样本点到超平面距离足够近 - 最大可分性：样本点在超平面上投影尽可能分开

中心化后（\(\sum_i x_i = 0\)），投影重构误差 \(\propto -\operatorname{tr}(W^{\mathrm{T}}XX^{\mathrm{T}}W)\)，于是两种等价优化目标： \[ \min_W -\operatorname{tr}(W^{\mathrm{T}}XX^{\mathrm{T}}W) \quad \text{s.t.} \quad W^{\mathrm{T}}W = I \quad \Longleftrightarrow \quad \max_W \operatorname{tr}(W^{\mathrm{T}}XX^{\mathrm{T}}W) \] 拉格朗日乘子法得 \(XX^{\mathrm{T}}W = \lambda W\)：对协方差矩阵 \(XX^{\mathrm{T}}\) 特征值分解，取前 \(d'\) 个最大特征值对应特征向量组成 \(W\)。

\(d'\) 的选取：用户指定，或交叉验证，或重构阈值（如 \(t=95\%\)）： \[ \frac{\sum_{i=1}^{d'} \lambda_i}{\sum_{i=1}^{d} \lambda_i} \geqslant t \] PCA 仅需保留 \(W\) 与均值向量即可投影新样本。舍弃最小特征值对应的特征向量，既提高采样密度，也能去噪（最小特征值常与噪声相关）。

10.4 核化线性降维（KPCA）

线性降维无法处理非线性嵌入（如 S 形曲面，需本真低维空间概念）。核化方法：令 \(z_i = \phi(x_i)\)，特征空间中 PCA 的解 \(W = \sum_i \phi(x_i)\alpha_i\)，代入特征方程并引入核函数 \(\kappa(x_i, x_j) = \phi(x_i)^{\mathrm{T}}\phi(x_j)\) 得： \[ K A = \lambda A \] 对核矩阵 \(K\) 做特征值分解，取 \(d'\) 个最大特征值对应特征向量。新样本 \(x\) 投影的第 \(j\) 维： \[ z_j = \sum_{i=1}^{m} \alpha_i^j \kappa(x_i, x) \] （需对所有样本求和，计算开销较大）

10.5 流形学习

流形：局部与欧氏空间同胚的空间——局部可用欧氏距离，可局部建立降维映射再推广到全局；降至 2/3 维可做可视化。

10.5.1 等度量映射（Isomap）

高维空间直线距离在低维流形上不可达，两点本真距离是测地线距离。计算方式： 1. 每个点按欧氏距离找近邻，建立近邻连接图 2. 用 Dijkstra 或 Floyd 算法求图上最短路径近似测地线距离 3. 用 MDS 求低维坐标

问题：近邻范围过大 → 距离很远的点被误连 → 短路；范围过小 → 图不连通 → 断路。新样本的低维坐标只能用回归学习器近似预测（权宜之计）。

10.5.2 局部线性嵌入（LLE)

与 Isomap 保持距离不同，LLE 保持邻域内样本间的线性重构关系： \[ x_i = w_{ij}x_j + w_{ik}x_k + w_{il}x_l \] 两步： 1. 对每个 \(x_i\)，在近邻集合 \(Q_i\) 上求重构系数（\(\sum_j w_{ij} = 1\)）： \[ \min_{w_{ij}} \left\| x_i - \sum_{j \in Q_i} w_{ij} x_j \right\|_2^2 \] 2. 低维空间中保持 \(w_{ij}\) 不变，求 \(z_i\)： \[ \min_Z \operatorname{tr}(ZMZ^{\mathrm{T}}) \quad \text{s.t.} \quad ZZ^{\mathrm{T}} = I \] 其中 \(M = (I-W)^{\mathrm{T}}(I-W)\)。解：\(M\) 最小的 \(d'\) 个特征值对应特征向量组成 \(Z^{\mathrm{T}}\)。

局部性思想：邻域外样本如何变化都不影响 \(w_{ij}\)、\(z_i\)。

10.6 度量学习

降维本质是寻找合适的距离度量 → 直接学习距离度量。

推广欧氏距离：属性加权 \(\|x_i - x_j\|_W^2 = (x_i-x_j)^{\mathrm{T}}W(x_i-x_j)\)，\(W = \operatorname{diag}(w)\)。但 \(W\) 非对角元为 0 意味着属性无关；属性相关时（如西瓜重量与体积）用一般半正定对称矩阵 \(M\)，得到马氏距离： \[ \operatorname{dist}_{\mathrm{mah}}^2(x_i, x_j) = (x_i - x_j)^{\mathrm{T}} M (x_i - x_j) \] \(M\) 即度量矩阵，度量学习即学习 \(M\)（须半正定：\(M = PP^{\mathrm{T}}\)）。

近邻成分分析（NCA）

把多数投票改为概率投票： \[ p_{ij} = \frac{\exp(-\|x_i - x_j\|_M^2)}{\sum_{l \neq i} \exp(-\|x_i - x_l\|_M^2)} \] 最大化留一法（LOO）正确率 \(\sum_i \sum_{j \in \Omega_i} p_{ij}\)（\(\Omega_i\) 为与 \(x_i\) 同类样本下标集），代入 \(M = PP^{\mathrm{T}}\) 得优化目标，求解即得度量矩阵。

必连/勿连约束（领域知识）

\(\mathcal{M}\) 必连、\(\mathcal{C}\) 勿连约束下的凸优化 [Xing et al.,2003]： \[ \min_M \sum_{(x_i, x_j) \in \mathcal{M}} \|x_i - x_j\|_M^2 \quad \text{s.t.} \quad \sum_{(x_i, x_k) \in \mathcal{C}} \|x_i - x_k\|_M \geqslant 1, \quad M \succeq 0 \]

度量学习与降维的联系：若学得的 \(M\) 低秩（秩 \(\operatorname{rank}(M) < d\)），对 \(M\) 特征值分解可得降维矩阵 \(P \in \mathbb{R}^{d \times \operatorname{rank}(M)}\)，度量学习结果可衍生出降维。

小结

概念 要点
kNN 懒惰学习；1NN 错误率 ≤ 2×贝叶斯最优
维数灾难 高维下密采样困难、距离计算困难
MDS 由距离矩阵求内积矩阵 \(B\)，特征值分解得低维坐标
PCA 最近重构性 = 最大可分性；\(XX^{\mathrm{T}}\) 特征值分解取前 \(d'\) 个
KPCA 核矩阵 \(K\) 特征值分解；投影需对所有样本求和
Isomap 近邻图最短路径 ≈ 测地线距离 + MDS；短路/断路问题
LLE 保持局部线性重构关系；\(M\) 最小特征向量

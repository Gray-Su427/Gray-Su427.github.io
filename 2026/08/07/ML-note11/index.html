《机器学习》自学日记（十一）

第十一章 特征选择与稀疏学习

11.1 子集搜索与评价

特征选择：从给定特征集合中选出相关特征子集的过程（重要数据预处理）。动机：① 缓解维数灾难（与降维是处理高维数据的两大主流技术）；② 去除无关特征降低学习难度。

注意：必须不丢失重要特征。冗余特征（信息可从其他特征推演，如“底面积”可由“底面长”“底面宽”得到）多数时候可去除，但若恰好对应“中间概念”则可能有益。

子集搜索（贪心策略）

  • 前向搜索：从空集开始，每轮加入一个使候选集最优的特征，直到加入任何特征都无法更优
  • 后向搜索：从完整集合开始，每轮去掉一个无关特征
  • 双向搜索：两者结合

贪心无法避免“局部最优”问题（如第二轮选了 \(a_5\) 优于 \(a_4\)，但第四轮 \(\{a_2,a_4,a_7,a_8\}\) 可能更优）——不穷举无法避免。

子集评价

用信息增益评价子集 \(A\)： \[ \operatorname{Gain}(A) = \operatorname{Ent}(D) - \sum_{v=1}^{V}\frac{|D^v|}{|D|}\operatorname{Ent}(D^v) \] 增益越大，包含的有助分类的信息越多。更一般地，特征子集确定了对 \(D\) 的一个划分，与真实标记划分差异越小越好——任何能判断划分差异的机制都可作为评价准则。

三类特征选择方法：过滤式（filter）、包裹式（wrapper）、嵌入式（embedding）。决策树本质就是一种嵌入式特征选择。

11.2 过滤式选择

先特征选择、再训练学习器，与后续学习器无关。

Relief

设计“相关统计量”度量每个特征的重要性，选取超过阈值 \(\tau\) 或最大的 \(k\) 个特征。

对每个样本 \(x_i\)：找同类最近邻猜中近邻 \(x_{i,nh}\) 与异类最近邻猜错近邻 \(x_{i,nm}\)，属性 \(j\) 的分量： \[ \delta^j = \sum_i -\operatorname{diff}(x_i^j, x_{i,nh}^j)^2 + \operatorname{diff}(x_i^j, x_{i,nm}^j)^2 \] - \(\operatorname{diff}\)：离散属性为 0/1（相等为 0），连续属性为规范化后的绝对差 - 猜中近邻距离 < 猜错近邻距离 → 属性 \(j\) 有益，增大分量；反之减小 - 时间开销随采样次数与特征数线性增长，效率高

Relief-F（多分类扩展）

对第 \(k\) 类的 \(x_i\)，猜中近邻在 \(k\) 类内找；猜错近邻在每个其他类中各找一个，按类比例 \(P_l\) 加权： \[ \delta^j = \sum_i -\operatorname{diff}(x_i^j, x_{i,nh}^j)^2 + \sum_{l \neq k} P_l \times \operatorname{diff}(x_i^j, x_{i,l,nm}^j)^2 \]

11.3 包裹式选择

直接把学习器性能作为评价准则，“量身定做”特征子集。性能通常优于过滤式，但需多次训练学习器，计算开销大得多。

LVW（Las Vegas Wrapper）

拉斯维加斯框架下随机子集搜索 + 交叉验证估计学习器误差。保留条件：误差更小，或误差相当但特征数更少。

问题：随机搜索 + 每次评价都训练学习器 → 计算开销大；初始特征多、\(T\) 大时可能长时间不达停止条件，有时间限制时可能给不出解。

11.4 嵌入式选择与 \(L_1\) 正则化

特征选择与学习器训练融为一体，同一优化过程完成。

线性回归平方误差 + 正则化： - \(L_2\) 范数（岭回归）：\(\min_w \sum_i (y_i - w^{\mathrm{T}}x_i)^2 + \lambda\|w\|_2^2\)，降低过拟合 - \(L_1\) 范数（LASSO）：\(\min_w \sum_i (y_i - w^{\mathrm{T}}x_i)^2 + \lambda\|w\|_1\)，更易得稀疏解

为什么 \(L_1\) 更易稀疏（几何直觉）：平方误差等值线与正则化等值线的交点——\(L_1\) 的等值线是菱形（角在坐标轴上），交点常落在坐标轴（某分量=0）；\(L_2\) 的等值线是圆，交点常在象限内部（分量均非零）。

\(w\) 稀疏 → 只有非零分量对应的特征出现在模型中 → \(L_1\) 正则化即嵌入式特征选择。

近端梯度下降（PGD）

对 \(\min_x f(x) + \lambda\|x\|_1\)，若 \(\nabla f\) 满足 \(L\)-Lipschitz 条件，每步迭代： \[ x_{k+1} = \arg\min_x \frac{L}{2}\left\|x - \left(x_k - \frac{1}{L}\nabla f(x_k)\right)\right\|_2^2 + \lambda\|x\|_1 \] 令 \(z = x_k - \frac{1}{L}\nabla f(x_k)\)，分量间互不影响，有闭式解（软阈值）： \[ x_{k+1}^i = \begin{cases} z^i - \lambda/L, & \lambda/L < z^i; \\ 0, & |z^i| \leqslant \lambda/L; \\ z^i + \lambda/L, & z^i < -\lambda/L. \end{cases} \]

11.5 稀疏表示与字典学习

两类稀疏性：① 特征稀疏（整列无关，特征选择处理）；② 零元素散布（如文档-字词矩阵，每行大量零元素）——文本字频表示的高度稀疏性使线性 SVM 在文本上表现很好。

字典学习（稀疏编码）：为稠密数据学一个字典，将样本转化为恰当稀疏的表示： \[ \min_{B, \alpha_i} \sum_{i=1}^{m} \|x_i - B\alpha_i\|_2^2 + \lambda \sum_{i=1}^{m} \|\alpha_i\|_1 \] \(B \in \mathbb{R}^{d \times k}\) 为字典矩阵（\(k\) 为词汇量，用户指定），\(\alpha_i\) 为稀疏表示。第一项要求重构误差小，第二项要求尽量稀疏。

交替优化： 1. 固定 \(B\)，对每个 \(\alpha_i\) 解 LASSO 型问题：\(\min_{\alpha_i} \|x_i - B\alpha_i\|_2^2 + \lambda\|\alpha_i\|_1\) 2. 固定 \(\alpha_i\)，更新 \(B\)：\(\min_B \|X - BA\|_F^2\)，用 KSVD（逐列更新，SVD 分解 \(E_i\) 时保留 \(\alpha^i\) 非零项以维持稀疏性）

11.6 压缩感知

问题：欠采样 \(y = \Phi x\)（\(\Phi \in \mathbb{R}^{n \times m}\)，\(n \ll m\)，欠定方程）能否精确恢复原信号 \(x\)？——若 \(x = \Psi s\) 且 \(s\) 稀疏，则可以。

两阶段：感知测量（如何获得稀疏表示：傅里叶/小波变换、字典学习）与重构恢复（精髓：从少量观测恢复原信号）。

限定等距性（RIP）：存在 \(\delta_k \in (0,1)\) 使 \((1-\delta_k)\|s\|_2^2 \leqslant \|A_k s\|_2^2 \leqslant (1+\delta_k)\|s\|_2^2\)，则 \(A\) 满足 \(k\)-RIP，可近乎完美恢复。

\(L_0\) 是 NP 难 → 用 \(L_1\) 代替（一定条件下共解）： \[ \min_s \|s\|_1 \quad \text{s.t.} \quad y = As \] 转化为 LASSO 等价形式用 PGD 求解，即基寻踪去噪（Basis Pursuit De-Noising）。

矩阵补全（应用：读者评分矩阵补全推荐）： \[ \min_X \operatorname{rank}(X) \quad \text{s.t.} \quad (X)_{ij} = (A)_{ij}, \ (i,j) \in \Omega \] \(\operatorname{rank}(X)\) 的凸包是核范数（奇异值之和 \(\|X\|_* = \sum_j \sigma_j(X)\)），转为凸优化 \(\min_X \|X\|_*\)，可用半正定规划（SDP）求解。理论上 \(A\) 秩为 \(r\) 时只需观测 \(O(mr\log^2 m)\) 个元素即可完美恢复。

小结

概念 要点
子集搜索 前向/后向/双向，贪心
子集评价 信息增益、划分差异
Relief 猜中/猜错近邻相关统计量；Relief-F 多分类
LVW 包裹式，随机搜索 + 交叉验证，开销大
LASSO \(L_1\) 正则化稀疏解；PGD 软阈值闭式解
岭回归 \(L_2\) 正则化，不稀疏
字典学习 交替优化 + KSVD；控制稀疏程度
压缩感知 RIP 条件；\(L_0 \to L_1\)；基寻踪去噪；矩阵补全/核范数
